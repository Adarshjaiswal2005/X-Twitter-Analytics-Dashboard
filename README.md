# X (Twitter) Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze X (Twitter) performance, engagement, impressions, clicks, and user interactions. The dashboard converts social media performance data into meaningful visual insights to support data-driven content strategy decisions.

## 📊 Project Overview

Social media platforms generate large volumes of performance data, making it difficult to manually identify trends and understand content performance.

This project provides an interactive dashboard that consolidates important metrics such as:

* Impressions
* Engagements
* Likes
* Retweets
* Media Views
* URL Clicks
* Hashtag Clicks
* User Profile Clicks
* Tweet Count
* Engagement Rate

The dashboard allows users to explore performance trends and identify the days and content patterns associated with stronger audience interaction.

## 🎯 Objectives

* Analyze the overall performance of tweets on X (Twitter)
* Track engagement, impressions, and user interactions
* Identify the best-performing days
* Analyze posting patterns and content performance
* Support data-driven social media strategy decisions

## 🔍 Dashboard Features

### Tweets & Impressions Analysis

* Weekly analysis of tweets and impressions
* Comparison of weekday and weekend activity
* Identification of high-performing posting days

The dashboard shows stronger activity during weekdays, particularly Tuesday to Thursday, while activity and impressions decrease significantly during the weekend.

### Engagement & Views Analysis

* Weekly engagement tracking
* Weekly views analysis
* Identification of high-engagement days

Thursday and Tuesday show the highest engagement and views, while Sunday records the lowest performance.

### Likes & Retweets

The dashboard compares likes and retweets to understand audience interaction.

* Likes: 7,883
* Retweets: 471

Likes are significantly higher than retweets, indicating strong content appreciation.

### Click Performance

The dashboard analyzes different types of clicks:

* URL Clicks: 2,829
* Hashtag Clicks: 2,568
* User Profile Clicks: 303

The analysis indicates that content containing links and relevant hashtags performs well in driving user engagement and actions.

### Posting Pattern Analysis

The dashboard analyzes tweet frequency by day.

* Highest tweet activity: Tuesday and Wednesday
* Lowest tweet activity: Saturday
* Weekday posting aligns with higher engagement days

## 🎛️ Dashboard Interactivity

The dashboard includes a **Month filter** that enables users to perform time-based performance analysis.

Interactive visuals allow users to dynamically explore trends, KPIs, engagement, and posting performance.

## 📚 Key Terminologies

| Term            | Definition                                                      |
| --------------- | --------------------------------------------------------------- |
| Impressions     | Number of times a tweet is displayed to users                   |
| Engagements     | Total interactions such as likes, retweets, clicks, and replies |
| Engagement Rate | Percentage of engagements relative to total impressions         |
| Likes           | Number of users who liked a tweet                               |
| Retweets        | Number of times a tweet was shared                              |
| URL Clicks      | Clicks on links included in tweets                              |
| Hashtag Clicks  | Clicks on hashtags                                              |
| Profile Clicks  | Clicks on the user's profile from tweets                        |
| Media Views     | Views of media content such as images or videos                 |
| KPIs            | Key Performance Indicators used to measure performance          |
